How the looks are chosen

Each new post takes the switched-on look that has done best so far, with the last few used going to the back, so the feed never shows the same look many times in a row. On Create you can pick one look, and on any post "Change look" re-makes it in another look with the same text (no new writing cost). Looks marked "free" use backgrounds drawn in code (paper, mandala, night lights, dusk sky): they cost nothing and shift a little with every post.
