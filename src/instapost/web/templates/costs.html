How the cost is kept low

  • {{ icon("check") }}
    Prompt caching
    The instructions and the verse list are the same for every post, so after the first post of the evening they are read from Claude's cache at 10% of the price.
  • {{ icon("check") }}
    Cheap checks first
    Free rule checks and the fact check run before any image or video, so a bad draft never costs more.
  • {{ icon("check") }}
    Right model per job
    Image checks use the small model; stories (one line) use {{ models.story or models.writer }}; reels and carousels use {{ models.writer }}.
  • {{ icon("check") }}
    Free photos
    Unsplash and your own image library cost nothing.
  • {{ icon("info") }}
    Waste
    Every Redo or Reject pays for a new post. Approving with small caption edits costs nothing.
